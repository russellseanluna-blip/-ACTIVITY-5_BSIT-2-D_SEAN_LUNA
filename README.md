ACTIVITY 5 - STACKS AND Queues
Name: Sean Russel Rey B Luna Course/Section BSIT-2D
This Python laboratory exercise shows how Stacks and Queues work through the use of arrays and linked lists. 
It covers their basic operations, handling errors such as overflow and underflow, checking balanced parentheses, 
and simulating a printing queue using the FIFO (First In, First Out) method.
